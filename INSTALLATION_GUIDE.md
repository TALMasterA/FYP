# TalknLearn installation and verification

TalknLearn is an Android translation and language-learning demo. The Android client uses Kotlin, Compose and Hilt. The backend uses Firebase Auth, Firestore, Cloud Functions and FCM. Azure handles translation and speech. Learning generation uses an OpenAI-compatible gateway through Cloud Functions. OCR uses ML Kit on the device.

## Build a clean checkout

Use JDK 17, Android SDK Platform 36, Git and Node 24 with npm. The minimum device version is Android 8.0 (API 26). The checked-in Gradle wrapper selects Gradle 8.14. Configure Android Studio or set `ANDROID_HOME` to the SDK location.

From the repository root on Windows PowerShell:

```powershell
Copy-Item ci/google-services-mock.json app/google-services.json
.\gradlew.bat testDebugUnitTest :app:detekt assembleDebug
```

On macOS or Linux:

```bash
cp ci/google-services-mock.json app/google-services.json
./gradlew testDebugUnitTest :app:detekt assembleDebug
```

Run the copy command in a fresh checkout. The mock configuration supports compiling and running tests. Live sign-in, translation and data synchronization require a Firebase project configuration. For those flows, use the configuration provided by the operator for the registered Android app `com.translator.TalknLearn`.

Open the root directory in Android Studio to launch on an emulator or device. For Google Sign-In, use an emulator with Google Play services and a Firebase OAuth client for the build's signing fingerprint. Debug builds require an operator-registered App Check token generated by that installation. A release build requires the correct signing fingerprint and Play Integrity validation. Confirm the installed app and APK use the same signer before attempting an in-place update.

## Run backend checks and Firestore emulator tests

From the root on Windows:

```powershell
Push-Location fyp-backend/functions
npm ci
npm run lint
npm run build
npm run test:coverage -- --runInBand
Pop-Location

Push-Location fyp-backend
firebase emulators:exec --only firestore --project demo-talknlearn "npm --prefix functions run test:emulator"
Pop-Location
```

The Firestore emulator uses JDK 21 and synthetic data under the demo project ID. CI pins the Firebase CLI used for this check. See [Test coverage](docs/TEST_COVERAGE.md) for report paths and instrumented coverage.

## Connect an authorized demo environment

- In Firebase, enable the intended Auth providers and register the project app and signing fingerprints. The app's login UI supports existing email/password accounts and Google Sign-In. The registration form returns a disabled-registration message. Google Sign-In can create accounts when Firebase signup is enabled.
- Select the Firebase project explicitly with `--project <project-id>` on any operator command. This repository's default alias points at the existing demo. Deploy only with owner approval. See [Firebase API and collections](docs/CLOUD_FUNCTIONS_API.md) and [Secrets rotation](docs/SECRETS_ROTATION.md).
- Keep the Speech and Translator keys in Functions secrets. Configure any learning gateway with the matching endpoint, API version, credentials and approved deployment. The Android client uses short-lived Speech tokens and the SDK connects directly to Azure for audio.
- Verify provider tiers and stage the current UTC month's allowance before deploying Functions from this branch. Provider operations pause when their approved policy is missing or spent. See [Demo spending and rollout](docs/DEMO_SPENDING.md).
- For a signed Play release, follow [Google Play release checklist](docs/GOOGLE_PLAY_RELEASE_CHECKLIST.md). For an interview demo, use an authorized account and create fresh translation history before testing generated learning material.

## Troubleshooting

| Symptom | Check |
|---|---|
| Android Gradle sync fails | Use JDK 17, confirm SDK Platform 36 is installed and check the SDK path. |
| Google Sign-In fails | Check the package, signing SHA-1, Android OAuth client and the device's Google Play services. |
| Callable returns unauthenticated after sign-in | Check App Check for the tester's own installation or verify Play Integrity for the release signer. |
| A provider operation is temporarily unavailable | Check the currently deployed Function and the app's provider policy, then inspect secret-version metadata and redacted function logs. |
| Firestore emulator cannot start | Use JDK 21, the CI-pinned Firebase CLI and a free local port. |
